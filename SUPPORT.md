# Support

| Need | Where |
|---|---|
| Bug in a Continentix product | Open an issue in that product's repository using the **Bug report** template |
| Feature or change proposal | Open an issue using the **Proposal** template; describe the problem before the solution |
| Security vulnerability | **Never** an issue — see [SECURITY.md](SECURITY.md) |
| Commercial enquiries, partnerships | [continentix.com](https://continentix.com) |

Continentix is operated by a single engineer. Issues are triaged in order of security impact, then production impact, then everything else. Response is not guaranteed on a fixed schedule, but every issue gets read.
