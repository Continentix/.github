# Continentix/.github

Organisation-level defaults for every Continentix repository.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public organisation profile shown at https://github.com/Continentix |
| `profile/banner.svg` | Profile banner |
| `SECURITY.md` | Default security policy (GitHub Security Advisories) |
| `CONTRIBUTING.md` | Engineering standard applied to every change |
| `CODE_OF_CONDUCT.md`, `SUPPORT.md` | Default community files |
| `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` | Default issue and PR templates |
| `workflow-templates/` | Starter CI workflows for the Rust, Laravel, and Flutter families |

Repositories may override any of these by shipping their own file with the same name.
